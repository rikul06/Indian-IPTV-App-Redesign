# Indian-IPTV-App-Redesign
A redesign of [kananinirav/Indian-IPTV-App](https://github.com/kananinirav/Indian-IPTV-App) with a channel browser modelled on the Tata Play TV app. The original shows hundreds of channels as one long unsorted list. This version groups them by genre and language and puts the most-watched channels first.
